控分中枢 — 便携完整版（文件夹移走即用）

一、如何启动（推荐）
  直接双击本目录内的 kongfenzhongshu.exe。
  程序会自动启动同目录内的后端 API（本地 127.0.0.1，端口在 8000～8099 内自动挑选空闲端口），关闭桌面窗口后会自动结束后端。

二、可选启动方式
  双击「启动控分中枢.bat」或运行「启动.ps1」等同于仅启动 kongfenzhongshu.exe（不再单独脚本拉后端）。
  说明：.bat 在资源管理器中的图标无法与 exe 完全一致；若要在桌面显示自定义图标，请对 kongfenzhongshu.exe 创建快捷方式，或选用本目录内的「控分中枢.ico」。

三、环境说明
  本目录已包含内嵌 Python 与运行依赖，接收方电脑无需再安装 Python。
  圣遗物 JSON 不会写入本文件夹；若在本机「配置管理」中保存过方案，会存在该电脑的应用数据里（与安装包无关）。换电脑或清空本机数据后需重新选文件或导入方案。

四、重新生成本文件夹

  在「最终交付」目录执行: python build_portable_full.py
  脚本默认会先构建前端 + Tauri，再复制 exe（避免便携包仍是旧界面）。
  仅改后端、确认 exe 已是最新时可加: python build_portable_full.py --skip-tauri-build
  需联网下载/更新内嵌 Python 与 pip 包（首次或升级版本时）。
  国内若 pypi.org 超时，脚本默认使用清华镜像；可 --skip-download 复用 _cache。

五、杀毒软件
  若误报，可将本文件夹加入信任区；本包由项目脚本从官方源组装生成。
